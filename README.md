# 光效智算 —— 分布式光伏项目投资收益智能测算与风险预警系统 V1.0

> 大学生创新创业训练计划项目软件成果｜软件著作权申报版本
> 开发单位：西南交通大学希望学院 大创项目组
> 技术栈：Python 3.10+ / Streamlit / Pandas / NumPy / Plotly / reportlab

本软件面向中小型 EPC 企业、校园与村镇光伏投资方、造价从业者，提供 **工程量组价 → 造价与财税测算 → 动态经济评价 → 多因子概率风险预警 → 报告导出** 的一体化投资决策辅助能力，全部基于开源技术栈，本地即可运行。

## 二、安装与启动

### 1. 安装依赖

```bash
cd 光效智算V1.0
pip install -r requirements.txt
```

国内网络可用镜像加速：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 启动软件

```bash
streamlit run main.py
```

启动后浏览器自动打开 `http://localhost:8501`；若未自动打开，手动复制该地址访问。关闭时在终端按 `Ctrl+C`。

### 3. 运行算法测试（可选，验证环境是否正常）

```bash
python tests/test_economics.py
```

预期输出：`用例总数 25，通过 25，失败 0`。

## 二·补、Windows 零基础安装（推荐）

不用记命令，按下面三步走：

1. 确认电脑已装 Python 3.10 以上：开始菜单搜索 `cmd` 打开命令行，输入
   ```
   python --version
   ```
   能看到 `Python 3.10.x` 及以上即正常；若提示"不是内部或外部命令"，去
   https://www.python.org/downloads/ 下载安装，**安装时务必勾选 Add Python to PATH**。
2. 双击文件夹中的 **`一键安装并启动.bat`**。它会自动创建独立环境 `.venv` 并安装依赖
   （首次 2~5 分钟，窗口不要关），随后自动启动软件并打开浏览器。
3. 以后每次使用，双击 **`启动.bat`** 即可（它优先使用已装好的 `.venv`，不再重复安装）。

> 若双击后窗口瞬间消失，说明 Python 未加入 PATH 或安装失败。请在该目录打开 cmd 手动执行
> `一键安装并启动.bat`，即可看到具体错误提示。

## 四、计算口径（重要）

1. **成本参数**为不含税金额（元）；**电价参数**为含税销售电价（元/kWh）。
2. **初始总投资** = 设备购置费 + 建安施工造价 + 并网配套费 + 前期咨询费。
3. **发电量** = 装机容量 × 年等效利用小时 × (1 − 弃光率) × 衰减系数；首年衰减 = 1 − 组件首年衰减，以后逐年乘 (1 − 后续年衰减率)。
4. **增值税** 按"销项税 − 进项税结转抵扣"计算：销项税 = 不含税收入 × 增值税率，进项税来自设备、建安、并网三类投资；**附加税** = 应交增值税 × 附加税率。
5. **折旧** 直线法：年折旧 = 初始投资 × (1 − 残值率) / 折旧年限，寿命末年回收残值。
6. **所得税** 以利润总额为基数，支持"三免三减半"（财务参数中设置免/减半年数）。
7. **净现金流** = 含税电费收入 + 补贴 − 运维费 − 保险费 − 融资利息 − 附加税 − 应交增值税 − 所得税。
8. **NPV** 按基准折现率折现；**IRR** 二分法求解 NPV=0；**回收期** 线性插值，静态口径折现率取 0。
9. **LCOE** =（初始投资 + Σ(运维+保险)折现）/ Σ发电量折现。

## 五、打包为 Windows 桌面程序（可选）

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --name 光效智算 ^
  --add-data "config.py;." --add-data "services;services" ^
  --collect-all streamlit main.py
```

打包后仍通过本地浏览器访问（Streamlit 架构本身是 Web 应用）。若打包遇到依赖收集问题，推荐直接分发源码 + `启动.bat`：

```bat
@echo off
cd /d %~dp0
streamlit run main.py
pause
```
